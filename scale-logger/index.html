      How to use
      

        
    
          
  1. Use Chrome or Edge (desktop) on the PC the balance is plugged into. This page works over HTTPS (GitHub Pages), from a local file, or from http://localhost. Close any other program using the COM port first.
    2. 
          
  2. First time: click Discover protocol. Put the 200 g weight on the pan, then press PRINT when asked. It finds baud rate and format.
    3. 
          
  3. Click Connect and pick the COM port.
    4. 
          
  4. print_key: weigh the bare part, wait for the stability mark, press PRINT on the balance. The reading logs itself. Repeat after gluing.
    5. 
          
  5. command / stream: press Capture (or Enter) instead of PRINT.
    6. 
          
  6. Bad shot: tick the flag before the part, or tick Exclude in the log. Rows are never deleted, only excluded.
    7. 
          
  7. Copy for Excel puts timestamp, part ID, before, after and direct net on the clipboard. Paste-special values into Weight Log cell B6.
    8. 
        

        
Run data is kept in this browser until you click New run. Download the CSV before closing.
