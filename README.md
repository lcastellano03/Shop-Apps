# Shop-Apps

Central landing page and home of all the shop apps. Enter the passcode, then tap an app to open it.

**Live site:** https://lcastellano03.github.io/Shop-Apps/

| Folder | App |
| --- | --- |
| `scale-logger/` | Scale Logger |
| `servo-press-qc/` | Servo Press QC (shaft, bearing, flux ring) and its one-page setup guide |
| `glue-program/` | Glue Program Calculator (`build.mjs` rebuilds `index.html` from `src/`; run it from inside the folder) |
| `hipot/` | Hipot Leakage R&R |

Each app is a plain static page, so adding one means adding a folder and a card in `index.html`.
